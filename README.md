# Aykan Kara - Personal Portfolio Website

Welcome to the repository for my personal portfolio website! This project is designed to showcase my skills, education, projects, and professional background through a clean, interactive, and modern web interface.

## 🌟 Features

- **Responsive Design**: Fully responsive layout that provides an optimal viewing experience across all devices (desktops, tablets, and mobile phones).
- **Bilingual Support (EN/TR)**: Custom-built multi-language functionality allowing visitors to seamlessly switch between English and Turkish.
- **Modern UI/UX**: Features a sleek "glassmorphism" aesthetic with smooth scrolling, dynamic hover effects, and CSS animations.
- **Downloadable CV**: Easy access to both English and Turkish versions of my resume directly from the navigation bar.
- **Project Showcase**: Highlights some of my key open-source projects including *SkyPass*, *Simple ATM Simulator*, and *Interactive Shopping Cart*.

## 🛠️ Technologies Used

- **HTML5**: For semantic structuring of the content.
- **CSS3**: For styling, responsive layouts (Flexbox/Grid), and visual effects (glass cards, background blobs).
- **Vanilla JavaScript**: For DOM manipulation, language toggling logic, smooth scrolling, and mobile menu interactions.
- **Font Awesome**: For clean and scalable iconography.
- **Google Fonts**: Custom typography using the 'Outfit' font family.

## 🚀 Getting Started

To view the website locally on your machine, simply follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/aykankara/PORTFOLYO.git
   ```
2. Navigate to the project directory:
   ```bash
   cd PORTFOLYO
   ```
3. Open `index.html` in your preferred web browser. No local server, dependencies, or build tools are required!

## 📂 Project Structure

- `index.html` - The main HTML structure containing all sections (Home, About, Projects, Skills, Contact).
- `style.css` - All styling rules, CSS variables, and responsive media queries.
- `script.js` - JavaScript logic for UI interactions and localization dictionaries.
- `Aykan_Kara_Resume_ENG.pdf` - English copy of my resume.
- `Aykan_Kara_Resume_TR.pdf` - Turkish copy of my resume.
